## 最小模型边界

### Category

`id`、`name`、`color`、`description`、`position` 是目录渲染的底线；`parent_category_id` 与 `subcategory_ids[]` 构建层级。统计（`topic_count`、`post_count`）及 `emoji` 是可选展示字段。当前 Flutter 解析支持三个 description 字段的回退，原生端应保持同一容错顺序。[models.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/models.dart:2234)

### Topic（首页/Category 列表）

`id`、`title`、`category_id`、`posts_count`、`views`、`like_count`、`created_at`、`last_posted_at`/`bumped_at`、`pinned`、`excerpt`，以及可经 `posters[].user_id → users[]` 关联的作者/最近回复者 `username` 与 `avatar_template`。`posts_count - 1` 是 Reply 数，首 Post 不算 Reply。[models.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/models.dart:2120)

### Topic 详情与 Post

详情至少使用 `post_stream.stream[]`、`post_stream.posts[]`、`posts_count`、`closed`、`archived` 及可选权限字段。每个 Post 最少为 `id,user_id,username,avatar_template,cooked,raw,post_number,reply_to_post_number,created_at`；`cooked` 用于渲染，`raw` 用于回复创建/可能的恢复匹配。`reply_to_post_number` 缺失表示对整个 Topic 的 Reply，而不是对某个具体 Post 的 Reply。[models.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/models.dart:2471)

## 已观察的容错与待验证项

- 列表和 Category 解析对缺失字段给默认值；Category 缓存读写失败可忽略。原生端应将“无数据”与“请求失败”分开呈现，而不是将解析默认值当成授权成功。[api.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/api.dart:1391) [categories_page.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/pages/categories_page.dart:71)
- Reply 创建响应已有两个形状和一个宽容回退解析器，但仓库没有对应的实际成功抓包。因此 API 23 真机必须验证：请求编码/`Content-Type`、服务端实际成功体、校验/限流错误体，以及请求超时后“按预期 post number 取详情”的恢复是否会误认其他人的 Post。[api.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/api.dart:71) [topic_page.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/pages/topic_page.dart:3711)
- User API Key 流程的密码学、WebView scheme 拦截和安全保存已由单独认证调研票定义；本契约只确认参考客户端的请求/回调字段。API 23 真机仍须验证授权页导航、`riverside://auth_redirect` 拦截、RSA PKCS#1 解密、nonce 校验和会话头实际可用性。[auth.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/auth.dart:196) [auth.dart](/Users/jackzhang/Code/DevEcoStudioProjects/RiversideApp/lib/auth.dart:203)
- 本文没有纳入搜索、通知、私信、发帖、图片上传、反应、投票、书签、钱包或推送；原生 MVP 不应为它们调用任何接口。
