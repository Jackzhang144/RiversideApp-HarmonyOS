# 06 — 图片选择、上传、保存与编辑器媒体

**What to build:** 让用户从系统相册选择图片，可靠上传到编辑器、头像、背景和后续 Chat，并在查看器中保存图片、复制链接或浏览器打开。

**Blocked by:** 04 — 发帖、编辑、引用、投票与草稿; 05 — 安全富内容渲染与链接导航.

**Status:** ready-for-agent

- [ ] 选择器只读取用户选择的媒体，立即复制到应用缓存后上传；不增加广泛相册权限。
- [ ] 上传进度、取消、失败和重试与发帖/发送分离；只有服务端上传成功才写入内容或资料状态。
- [ ] SaveButton 或官方授权流程保存图库，覆盖拒绝、过期和成功反馈；物理 Phone 验收通过。
