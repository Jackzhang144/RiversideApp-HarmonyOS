# 02 — 建立五 Tab HDS 正式根导航

**What to build:** 将正式应用根导航升级为原型确认的五 Tab HDS 悬浮导航，让首页、Category 和我的继续承载真实流程，同时把聊天和消息呈现为明确不可用且不会改变当前页面的产品方向占位。

**Blocked by:** 01 — 固化持久 UI 原型实验区.

**Status:** ready-for-agent

- [ ] 根导航按首页、Category、聊天、消息、我的顺序显示五个系统 Symbol Tab，并采用 API 23 支持的 HDS 悬浮材质与底部安全区适配。
- [ ] 首页、Category 和我的能够切换并保留现有根选择语义；Topic、认证和 Reply 仍由二级导航承载。
- [ ] 聊天和消息视觉降级、无选中态、无页面跳转、无提示、无业务请求，无障碍文案明确读出“未实现”。
- [ ] 根页面不能通过左右滑动进入聊天或消息，也不能让占位 Tab 成为 AppShell 的选中目的地。
- [ ] 通过现有最高层 AppShell 测试接缝验证三个可用目的地和两个不可用占位的外部行为，不断言组件树实现。
- [ ] 原型入口与原型内部导航继续可用，正式根导航不引用 Fixture 或原型状态。
- [ ] 使用 `devecocli` 完成 API 23 构建与基础交互验证，且不修改或提交本地签名配置。
