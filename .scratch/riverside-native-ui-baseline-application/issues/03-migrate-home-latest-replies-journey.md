# 03 — 迁移 Home 最新回复完整路径

**What to build:** 将原型确认的 Home 层级应用到真实 Latest Replies 流程，让用户获得原生标题、排序标签、Topic 卡片和下拉刷新体验，同时清楚区分尚未实现的排序、搜索和发布能力。

**Blocked by:** 02 — 建立五 Tab HDS 正式根导航.

**Status:** ready-for-agent

- [ ] Home 作为根页面显示 Riverside 标题且没有返回操作；搜索和发布新 Topic 图标视觉降级、无响应，无障碍文案标注“未实现”。
- [ ] 排序标签栏显示最新回复、最新发表、未读、热门和精华，并可横向滚动以展示全部标签。
- [ ] 只有最新回复能够成为选中内容并使用真实服务端数据；其余四个标签不切换内容、不发请求，并明确呈现“未实现”。
- [ ] 真实 Topic 使用可复用卡片展示作者、更新时间、置顶状态、标题、摘要、Category、Reply 数和浏览数，并能打开对应 Topic。
- [ ] initial、loading、content、empty 和 error 状态具有一致的原生层级与可恢复操作。
- [ ] 下拉刷新使用现有 Latest Replies 契约；刷新期间保留已有内容，刷新失败后仍保留内容并给出非阻塞反馈。
- [ ] AppShell 自动测试覆盖首次加载、空态、失败、重试、内容刷新和刷新失败保留内容，并证明占位操作不会产生请求或导航。
- [ ] 使用 `devecocli` 完成 API 23 构建与 Home 关键路径验证，且不修改或提交本地签名配置。
